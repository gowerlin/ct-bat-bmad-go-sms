### 衝突檔逐一說明
**`cmd/smsd/main.go`**（唯一衝突檔，衝突區塊只有 `st := store.New(time.Now)` 之後的組裝幾行）
- `main`（T0010）的意圖：provider 改由設定選擇（`PROVIDER` 切換 mock／mitake，D019），所以 `prov := mock.New()` 換成 `prov, err := newProvider(os.Getenv, time.Now)`，失敗時 `logProviderError` ＋ `os.Exit(1)`，並拿掉 `mock` import；`queue.NewInProcess(st)` 不動，舊註解「consumed by the queue workers from Story 1.6」原樣保留。
- `ct/T0008` 的意圖：佇列 worker 要實際呼叫 provider 發送，所以把 `prov` 移到建 queue 之前，改成 `queue.NewInProcess(st, queue.WithProvider(prov))`，並刪掉已實現的「consumed by … Story 1.6」註解；provider 的選擇不動（仍 `mock.New()`）。
- 解法：
  ```go
  st := store.New(time.Now)
  prov, err := newProvider(os.Getenv, time.Now)
  if err != nil {
  	logProviderError(slog.Default(), err)
  	os.Exit(1)
  }
  q := queue.NewInProcess(st, queue.WithProvider(prov))
  ```
- 理由：兩邊改的是同一段的不同面向（T0010 管「用哪個 provider」，T0008 管「queue 拿到 provider」），沒有語意衝突，照工單〈做法〉第 2 步兩邊都保留。`mock` import 在 git 自動合併的 import 區塊已不存在（取 `main` 那邊），沒有未使用的 import 或變數（`go build`／`go vet` 乾淨）；`err` 沿用 `net.Listen` 那行已宣告的變數，`prov` 是新變數，`:=` 合法。T0008 刪註解的意圖一併保留。合併結果相對 parent1 只動這幾行（`git diff 1b0dabb abc1eba -- cmd/smsd/main.go`），相對 parent2 只多了 T0010 的 `newProvider` 錯誤處理與拿掉 `mock` import。
