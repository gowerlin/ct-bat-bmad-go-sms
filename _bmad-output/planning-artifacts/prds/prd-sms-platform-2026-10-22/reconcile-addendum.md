# 輸入對照報告：brief addendum 對 PRD

輸入：`briefs/brief-sms-platform-2026-10-22/addendum.md`
比對對象：同專案 `prds/prd-sms-platform-2026-10-22/prd.md` 與同資料夾 `addendum.md`
範圍：只報告缺口，不改寫。

## 結論摘要

四個類別都大致被承接。技術限制四條逐字承接，租戶隔離與 E2E 品質要求已轉成 FR-20、FR-22 至 FR-24，補查項目列在 PRD §8 與 PRD addendum。下列為漏掉、弱化或矛盾之處，依嚴重度排序。

## 缺口

### G1（高）法遵理由沒有變成可驗收的需求
- 輸入：國外 CPaaS 因法遵（發送紀錄外送）被排除。
- PRD：只在 §2.1 JTBD 寫「法遵單位要確認發送紀錄不外送」。§4 沒有任何對應 FR 或驗收條件。排除理由只出現在 PRD addendum，PRD 本文與 §5 非目標都沒寫。
- 影響：這是自建的主要理由，卻沒有約束。例如：發送紀錄與日誌的儲存位置、`mitake` Adapter 以外的 Provider 日後是否必須在境內，都沒有規定。有人日後新增國外 Adapter（FR-4 容許任何 Adapter）時，PRD 無法擋。
- 建議處理：補一條資料落地或不外送的約束，或明寫為假設並列入 §9。

### G2（高）「補查」的時機被延後，且沒有擋點
- 輸入：「建議在 **PRD 前**補查」三項（TCO 與 30 萬則／月數字、開源閘道與國內聚合商比較、五團隊行為差異清單）。
- PRD addendum：改成「建議在**架構前**補查」，時機被悄悄後移。PRD 已在三項都缺的情況下成稿。
- PRD §8 Q2、Q3、Q6 只是列為待決，沒有負責人、期限，也沒說誰有權決定「不做自建」。輸入稱此為「最大的決策風險」，PRD 以 Q1「不阻擋」的語氣處理，風險被弱化。
- 影響：若比較結果偏向現成方案，整份 PRD 作廢，而 PRD 沒有標明這個前提。
- 建議處理：在 PRD 開頭或 §8 標明「本 PRD 以自建為前提，前提未驗證」，並為 Q2、Q3、Q6 指定擋點（架構開工前或遷移前）。

### G3（中）行為差異清單未進入驗收，SM-1 沒有基準
- 輸入：差異清單「作為遷移與驗收基準」。
- PRD：SM-1 要求各團隊行為「與其他團隊完全相同」，但沒有現況基準，也沒有遷移驗收條件。差異清單只在 §8 Q6 出現。
- 影響：無法判斷換接前後哪些行為差異是刻意收斂、哪些是破壞。SM-1 的「完全相同」只能驗證閘道自己一致，不能驗證相容。
- 建議處理：SM-1 或新增遷移驗收項，引用差異清單，並把清單列為前置輸入。

### G4（中）重啟丟佇列的後果沒有行為規定
- 輸入：重啟會丟佇列。PRD §4.3 說明「已接受的限制」。
- 缺口：FR-1 已回 202 並給 `id`。重啟後該訊息是否仍可 GET、Status 停在 `queued` 還是消失、租戶如何得知，都沒有驗收條件。PRD addendum 只留「終態訊息保留期限」給架構，未涵蓋重啟後的訊息紀錄。
- 影響：SM-2「單點查證」與 FR-2 在重啟後可能對不上。
- 建議處理：至少寫明重啟後的預期行為（例如明定不保證），並讓接入團隊知悉。

### G5（低）推論被寫成限制，另有容量數字未落成需求
- PRD addendum 寫「測試指令為 `go test ./... -race`，因此實作語言為 Go」。輸入並未規定語言，這是從 FR-23 反推，卻放在「技術限制（承接自 brief addendum）」之下，混淆了來源。UJ-1 的「Go 後端工程師」是 persona，不是限制。
- 輸入提到「約 30 萬則／月」的規模。PRD 沒有任何容量或吞吐需求，FR-1 的 p95 < 200 ms 也沒有負載條件；FR-16 只在 §8 Q3 提到要參考該數字。
- 建議處理：把語言標為決定或假設，並移出「承接」小節；為預期流量補一條基準或明標未定。

## 已承接，無缺口

- 單一程序、in-process 佇列、無法多副本：PRD §4.3、§5、addendum。
- 佇列介面抽象以便換 Redis：FR-7（Redis 一詞只在 PRD addendum 出現）。
- Adapter 只打假對端：FR-5、FR-6、§5。
- 同供應商重試 3 次、不做 failover：FR-8、FR-9。
- 共用 SDK 被排除的理由：PRD 本文未寫，但 addendum 有，且與願景一致。
- 租戶隔離測試覆蓋：FR-20。
- 每功能 E2E：FR-22 至 FR-24（涵蓋 4.1 至 4.7，4.8、4.9 本身不在範圍，可接受）。
