- (decision) AD-1 [ADOPTED 使用者] Provider 介面只有 Send/ParseCallback/Name；adapter 不重試，重試歸 queue。與 provider.go 現況一致。防止：adapter 內各自重試造成 attempts 與 FR-8 的 4 次呼叫失準
- (decision) AD-2 [ADOPTED 使用者] queue 套件以介面隔離；v1 in-process；之後可換 Redis，呼叫端不改（FR-7）
- (decision) AD-3 [ADOPTED 使用者] webhook 入站（供應商回呼）與出站（HMAC-SHA256 簽章通知租戶）分開；同一 (message id, status) 只送一次
- (decision) AD-4 [ADOPTED 使用者] tenant_id 由 API key 解出後貫穿 store 每筆查詢；跨租戶一律 404 not_found
- (constraint) [ADOPTED 使用者] net/http 標準庫優先、不加外部依賴；E2E 用 httptest；套件沿用 cmd/ 與 internal/{httpapi,provider,queue,webhook,template,ratelimit,tenant,store}
- (decision) AD-5 Message.status 轉移集中在 store 的單一轉移表，以 compare-and-set 套用；終態不可變；轉移成功與 OutboundNotification 入 outbox 為同一原子操作，(message_id,status) 唯一鍵即去重。防止：queue 與入站回呼競態、重複通知。取捨：不讓 queue 直接依賴 webhook
- (decision) AD-6 回呼先於 sent 寫入時：ProviderRef→message 對應與 sending→sent 同一次 CAS 寫入；其前到達的回呼回 404 not_found（FR-10）[ASSUMPTION]，假對端須在 Send 回應後才回呼
- (decision) AD-7 FR-19 回呼驗證：由 adapter 在 ParseCallback 內驗證（共用密鑰 header，constant-time 比較），失敗回 provider.ErrUnauthorized，webhook 入站映射為 401。因介面固定三個方法，驗證不可另開方法
- (decision) AD-8 錯誤：領域套件只回 sentinel error，唯有 httpapi 對應 code/status 並以單一 writeError 輸出信封；500 不洩漏內部資訊
- (decision) AD-9 FR-29 對外連線：所有 http.Client 由 cmd/smsd 組裝並注入，Transport 以允許清單（設定的 Provider 位址＋租戶 Webhook URL）把關；程式碼其他處不得 new http.Client 或用 DefaultClient
- (decision) AD-10 時間與隨機源注入：queue/ratelimit/webhook 以 Clock 介面取時間（e2e/testutil.FakeClock），不得直接 time.Now/time.Sleep；id 用 crypto/rand
- (decision) AD-11 設定：單一 JSON 設定檔（stdlib 無 YAML）＋環境變數 PROVIDER 等；啟動時載入一次，非法即 fail-fast；API key 只存 SHA-256 hex；變更需重啟（FR-21）
- (decision) AD-12 限流：token bucket，每 API key 一桶，容量與補充率取自所屬租戶 rate_limit_per_min，未設定用預設 60 [ASSUMPTION]；順序 authenticate→ratelimit→handler；Retry-After=ceil(秒) 且 ≥1。Q3 數字未查，預設值待校準
- (decision) AD-13 重試排程 [ASSUMPTION，FR-8/12 留給架構]：Provider 重試 3 次，指數退避 1s/2s/4s 無 jitter；attempts=對 Provider 呼叫次數（最多 4）；Webhook 通知重試 3 次，同 1s/2s/4s；用盡記錄 slog 失敗，不改 Message.status
- (decision) AD-14 容量 [ASSUMPTION，PRD Q8]：佇列有界 1000；滿載 POST 回 503 code=queue_full；終態訊息記憶體保留 24h 後清除（保留期內 GET 可查，過期 404）。峰值吞吐假設未查（Q3）
- (decision) AD-15 日誌 slog JSON 到 stdout，只記 message id/status/tenant_id；不記號碼、內容、API key、簽章密鑰
- (decision) AD-16 模板渲染在 httpapi 呼叫 template.Render 後才入佇列；缺變數 template 回 sentinel，httpapi 對應 422
